# The stylesheet

`assets/css/vola.css` (~108KB) is the **entire** stylesheet and the source of
truth. `design-system/vola/MASTER.md` *describes* it. If they disagree, the
CSS is right and MASTER.md has gone stale — fix MASTER.md.

`assets/css/fonts.css` is generated by `tools/fonts-fetch.mjs`. Do not
hand-edit it; the settings deny rule will stop you.

## `[hidden]` is a hint, and `display` outranks it

There is one global rule near the top:

```css
[hidden] { display: none !important; }
```

It exists because ten `.thing[hidden] { display: none }` patches had already
accumulated, one per component that found out the hard way — and an eleventh
was live in production: `.field { display: grid }` kept all six delivery
address fields visible on the bag page after `cart.js` had hidden them, so
the form asked for an address directly above its own line saying the address
is collected on the next step (`15a5294`).

**Do not add another per-component `[hidden]` rule.** The global one covers
it. If something needs to be visible while carrying the attribute, that is a
sign the attribute is the wrong tool.

## Checks after any change to a wide element

- **No horizontal scroll at 375px.** A table needs `.tablewrap`; a grid item
  needs `min-width: 0`.
- **AA contrast, verified programmatically** rather than eyeballed.
- `prefers-reduced-motion` honoured, focus states visible.

Verify by measurement, not by eye — screenshots time out often in this
environment. `document.documentElement.scrollWidth - clientWidth`, bounding
rects and computed styles are the reliable path. The `verify` skill has the
loop.

## Tokens

Real names are `--c-*` and `--space-N`. `--radius: 0` — the square is
deliberate. Two-accent contrast rule. Components: `.btn`, `.card`,
`.input`/`.field`, `.drawer`. **There is no centred modal.**
