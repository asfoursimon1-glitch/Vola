> If that file exists, its rules **override** this Master file.

> values below into new CSS — reference the variables.

**Translucent chrome** — the nav and drawer sit on these, not on solid fills:
`--glass-bg: rgba(250,248,245,0.82)` · `--glass-border: rgba(12,10,9,0.08)` ·
`--scrim: rgba(12,10,9,0.52)`.

> **Two accents, and the reason matters.** `--c-accent` is 4.8:1 on white —
> AA for the small uppercase text it carries. On `--c-indigo-900` that same
> brass drops to **3.3:1 and fails**. `--c-accent-on-dark` (5.9:1) exists only
> for that case. Both ratios were measured, not estimated. **Never use
> `--c-accent` on a dark band.**

### Typography

- **Display:** Cormorant — 300, 400, 500, and 300 italic
- **UI / body:** Montserrat — 400, 500, 600
- **Mood:** luxury, high-end, fashion, elegant, refined, premium

**Self-hosted.** `assets/css/fonts.css` is generated by `tools/fonts-fetch.mjs`
and linked from every page's `<head>` *before* `vola.css`, so the two download
in parallel. Only the faces above are subsetted (`latin`, `latin-ext`), with
`font-display: swap`. `assets/fonts/OFL.txt` must travel with them.

> ⛔ **Do not add a Google Fonts `@import` or `<link>`.** The self-hosting is
> deliberate: it removes a third-party request, and `assets/js/pages/privacy.js`
> scans the DOM for exactly that link and will report the site as contacting a
> font provider if one reappears.

```css
--font-display: 'Cormorant', 'Didot', Georgia, 'Times New Roman', serif;
--font-ui: 'Montserrat', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
```

### Radius, shadow, motion tokens

```css
--radius:      0px;     /* Swiss / editorial — square by default */
--radius-pill: 999px;   /* chips and badges only */
```

> **The site is square.** Rounded corners are the single loudest way to make
> this look like a generic template. `--radius-pill` is the only exception.

| `--shadow-sm` | `0 1px 2px rgba(12,10,9,0.05)` |
| `--shadow-md` | `0 12px 32px -12px rgba(12,10,9,0.18)` |
| `--shadow-lg` | `0 32px 64px -24px rgba(12,10,9,0.28)` |

Note the large negative spread: shadows here are wide and faint, a lift rather
than a drop. Duration `--dur-fast 150ms` / `--dur-base 260ms` /
`--dur-slow 420ms`; easing `--ease-out cubic-bezier(0.16,1,0.3,1)` and
`--ease-inout cubic-bezier(0.65,0,0.35,1)`.

z-scale: `--z-base 0` · `--z-raised 10` · `--z-sticky 40` · `--z-overlay 100` ·
`--z-toast 1000`.

## Component Specs

These are the classes that exist. **Use them; do not write parallel ones.**
`vola.css` is organised into 21 numbered sections — find the right one and add
there.

### Buttons — `.btn` + a variant

Square, uppercase, `--ls-mid` tracking, `min-height: 48px`, `padding: 0 var(--space-5)`,
`font-size: var(--t-sm)`, weight 500.

| Variant | Appearance |
|---|---|
| `.btn--primary` | Solid `--c-primary`; hover → `--c-indigo-700` |
| `.btn--accent` | Solid brass, with a single soft sheen sweep on hover (not a loop) |
| `.btn--ghost` | Transparent, 1px `--c-fg` border; hover inverts to solid |
| `.btn--on-dark` | Translucent white border for indigo bands; hover inverts |
| `.btn--success` | Momentary confirmation after add-to-bag |

Modifiers: `.btn--block` (full width), `.btn--sm` (40px). `.btn__spinner` for
in-flight state. Disabled is `opacity: 0.45` via `:disabled` **or**
`[aria-disabled='true']`.

Feedback is split across two independent properties on purpose: `:active` uses
`filter: brightness(0.92)`, while `transform` is left free for the magnetic
hover in `motion.js`. **Never declare a `transform` transition on `.btn`** — it
would add lag to cursor tracking.

### Product card — `.card`

**Transparent. No border, no shadow, no radius, no padding.** The image does
the work: `.card__media` is a `4/5` box with `overflow: hidden` over
`--c-muted`, and `.card__img` scales to `1.045` on hover — inside the clip, so
nothing shifts. `.card__flag` / `.card__flag--accent` sit top-left.
`.card__name a::after { inset: 0 }` makes the whole card one target, so the
outline goes on `.card:focus-within`, not the link.

Prefer `V.card(product)` / `V.cardWithFit(product)` in `app.js` over
hand-written markup.

### Inputs — `.input`, wrapped in `.field`

`min-height: 48px`, square, `1px solid var(--c-border-strong)`, white fill.
Hover darkens the border, `:focus-visible` takes `--c-ring`, and
`[aria-invalid='true']` takes `--c-destructive`.

`.field` is the grid wrapper carrying `.field__label`, `.field__hint`, and
`.field__error` (which contains an icon and is toggled with `[hidden]`).
`V.formField()` builds the whole thing — use it, so the error/`aria-invalid`
wiring stays consistent.

### Overlays — `.drawer` + `.overlay`

**There is no centred `.modal`.** Layered surfaces on this site are a
side drawer (`.drawer` with `.drawer__head` / `__body` / `__foot`, toggled by
`[data-open]`) over a `--scrim` backdrop, using the glass tokens. The bag,
filters and preferences all use it. `V.overlay()` and `V.openCart()` are the
entry points; `body.is-locked` handles scroll lock.

### Chips — `.chip`

The one pill in the system (`--radius-pill`): removable filter tokens inside
`.chips`, which hides itself when empty.

### Icons

An **18-icon hand-drawn set** lives in `app.js` and renders through
`V.icon(name, { label })`: `bag, menu, close, search, plus, minus, check,
arrow, alert, scissors, leaf, truck, box, ruler, pin, instagram, pinterest,
tiktok`. All on a `256` viewBox, `stroke: currentColor`, `stroke-width: 14`,
round caps and joins.

> Not Heroicons or Lucide — those were the brief's suggestion and were never
> used. Adding a second icon library would put two stroke languages on one
> page. Draw a nineteenth path in that set instead, matching the weight.

## Style Guidelines

**Style:** Editorial Minimalism — Swiss grid, generous negative space,
square edges, large display type at low weight, with **translucent chrome**
(nav and drawer) as the one soft material.

**Keywords:** editorial, grid, restraint, negative space, denim, brass,
translucency

> The brief said **"Liquid Glass"** — Apple-platform lensing and refraction.
> That is not what was built and would fight the Swiss grid. The translucency
> survives, confined to nav and drawer.

### Page pattern

A storefront, not a landing page: **16 pages, each with its own shape.** The
brief's fixed "Hero → feature grid → social proof → CTA" order does not apply
outside the homepage. What is consistent:

- A `.sec-head` introduces each section (eyebrow + display title).
- Editorial pages (`about`, `care`, `traceability`, `privacy`) use `.prose`,
  capped at `--wrap-text` for line length.
- Facts in copy are **derived, not written** — prices, counts, ratings,
  shipping terms and privacy claims all come from `VOLA.terms`, `VOLA.house`,
  `data.js` or config. See `CLAUDE.md`.

## Motion

**No animation library. No GSAP.** The brief's `gsap.from(...)` stagger recipe
was never used — this site has zero dependencies, and it is not worth 70KB to
reproduce what five lines of IntersectionObserver already do.

| Layer | Where | Behaviour |
|---|---|---|
| Scroll reveal | `[data-reveal]` in CSS, observed in `app.js` | `opacity 0` + `translateY(18px) scale(0.985)` → `.is-in`, over `--dur-slow`. Stagger via `--reveal-delay`; `V.stagger(nodes)` sets it. |
| Hero load-in | `[data-hero-in]` | Runs once on load, **pure CSS** — each element carries `--hi` (its index) and the delay is `calc(var(--hi) * 100ms + 120ms)`. No JS. |
| Parallax | `[data-parallax]`, `motion.js` | rAF-throttled, IntersectionObserver-gated, clamped to 5% of element height — the CSS oversizes these images 12% so the clip edge can never show. |
| Magnetic CTA | `motion.js` | Hero and accent buttons track the cursor (±7px / ±5px), spring back on leave with an inline `cubic-bezier(0.34,1.56,0.64,1)`. Fine pointers only; excluded on `.btn--block`. |
| Hearts | `motion.js` | A blue heart drifts up where the visitor clicks. Decorative, `aria-hidden`, `pointer-events: none`, throttled to 120ms. |
| Page transitions | `@view-transition` | Same-origin navigations crossfade at 320ms. Inert where unsupported — not a fallback needing maintenance. |

**Reduced motion is a teardown, not a skip.** `motion.js` returns early under
`prefers-reduced-motion: reduce`, *and* listens for a live change to that media
query so it can rip out parallax, magnetism and hearts mid-session — and
restore them. Any new motion must do the same.

## Anti-Patterns (Do NOT Use)

- ❌ Vibrant, block-based, or playful colour
- ❌ **Rounded corners** — `--radius` is `0`; only `.chip` is a pill
- ❌ **Emojis as icons** — use the `V.icon()` set
- ❌ **A second icon library** — extend the existing set instead
- ❌ **A Google Fonts link or `@import`** — the fonts are self-hosted, and the
  privacy page audits for this
- ❌ **A `transform` transition on `.btn`** — it lags the magnetic hover
- ❌ **A centred modal** — use `.drawer`
- ❌ **Bold headings** — headings are weight 400 by design
- ❌ Layout-shifting hovers (scale inside an `overflow: hidden` box is fine)
- ❌ Low contrast text — 4.5:1 minimum, and see the two-accent rule above
- ❌ Instant state changes — use the `--dur-*` tokens
- ❌ Invisible focus states — `:focus-visible` is styled globally; do not remove it
- ❌ Hard-coded hex, px spacing, or a restated fact — use the tokens and the data

### Breakpoints

There is no fixed breakpoint ladder — queries are content-driven, at the width
where each layout actually breaks (`520`, `560`, `640`, `700`, `860`, `900`,
`1023`, `1024`). **Test at 375 / 768 / 1024 / 1440** regardless.

## Pre-Delivery Checklist

- [ ] No hard-coded colours, spacing or radii — tokens only
- [ ] Square by default; no stray `border-radius`
- [ ] Icons from the existing 18-icon set, via `V.icon()`
- [ ] `cursor: pointer` on everything clickable
- [ ] Transitions on state changes, using `--dur-*` and `--ease-*`
- [ ] Contrast ≥ 4.5:1 — **measured**, and `--c-accent-on-dark` used on indigo
- [ ] Focus states visible; `:focus-visible` intact
- [ ] `prefers-reduced-motion` respected **and torn down on live change**
- [ ] Responsive at 375 / 768 / 1024 / 1440
- [ ] **No horizontal scroll at 375px** — wide tables need `.tablewrap`, grid
      children need `min-width: 0`
- [ ] Nothing hidden behind the sticky nav (`--nav-h`, `scroll-padding-top`)
- [ ] No new user-facing fact that could go stale — derive it
